AgentBuddy 搭子，是连接你自己的电脑与 AI 编程 Agent 的原生客户端。离开桌面，也能在 iPhone 和 iPad 上查看任务进展、继续对话、处理操作请求。

任务、项目、主机，一处管理
按任务与项目整理工作，打开已有会话，或在已连接的主机上发起新的编程任务。

看见进度，也看清细节
实时阅读 Agent 回复、代码块、图片和命令输出。上下文留在会话中，随时接着做。

关键操作，由你决定
查看审批请求，选择允许或拒绝；在任务进行中继续补充说明，让 Agent 按你的意图推进。

连接你控制的主机
支持局域网发现、主机配对和 SSH 连接。可用 Agent 取决于主机上安装和配置的软件。

贴合移动使用习惯
支持适用场景下的语音输入，以及浅色、深色主题，用熟悉的原生界面处理编程工作。

使用前需要准备兼容的主机，并安装、配置相应的编程 Agent。App 不包含 AI 模型订阅；第三方服务可能需要独立账户、API 权限或付费。

AgentBuddy 是面向兼容编程 Agent 的独立开源客户端。可用的 Agent 与模型取决于你在主机上配置的软件和服务。

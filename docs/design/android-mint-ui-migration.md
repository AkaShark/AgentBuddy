# Android Mint UI 重构：功能迁移与验收记录

日期：2026-09-27。分支：`android-ui-mint-rebuild`（基于 `main` 的 `b7f41ac`）。依据：`docs/design/mobile-ui-rebuild-handoff.md`、`docs/design/ios-mint-ui-migration.md` 与 `artifacts/design/agentbuddy-ui-v1/`。

本文件先记录重构前 Android 的全部入口和能力，以及它们在新界面中的位置。实现完成后补充结构、验证与已知问题。

## 1. 重构前的入口与能力

基线截图来自 Pixel 9（Android 16，未保存任何主机，仅「本设备」）：首页（新手引导气泡 + 空态小猫）、设置、添加服务器、新建会话输入框、搜索、会话列表按钮。

### 导航

- 手写返回栈 `navStack: List<Route>`（`ui/AgentBuddyApp.kt`），没有 androidx.navigation。进入会话会把栈重置为 `[Home, Conversation]`。
- 发现、设置、账号、目录选择、项目选择是根级 `ModalBottomSheet`，由一个 `BackHandler` 按优先级关闭。
- `snapshot.activeThread` 变化时自动跳到对应会话。通知、语音交接、分叉和新建会话都走这条路径。
- 没有平板 / 宽屏分栏布局，因此没有需要保留的分栏。
- `Route.Sessions`、`ServerInfo`、服务器壁纸页在现有代码里没有入口（`/resume` 的回调也没接上）。

### 功能去向

| 现有能力 | 旧入口 | 新位置 |
|---|---|---|
| 打开任务 | 首页卡片点击 | 任务页卡片点击 |
| 快捷回复、固定 / 取消固定、分叉、停止本轮、删除 | 首页卡片长按菜单；右滑回复 | 任务卡片「…」菜单、长按菜单；右滑回复 |
| 隐藏任务 | 首页卡片左滑 | 任务卡片左滑、「…」菜单 |
| 搜索任务（服务端搜索，250 ms 防抖，运行时筛选，下拉刷新） | 首页 🔍 胶囊 | 任务页顶部搜索按钮 |
| 全部任务（过滤、排序、分组、分叉、重命名、归档） | 无入口（`SessionsScreen` 未接入） | 任务页「全部任务」；`/resume` 同样进入 |
| 主机筛选 | 首页主机胶囊点击 | 任务页顶部主机菜单，附「管理主机」 |
| 主机重连、重启服务、重命名、移除 | 主机胶囊长按 | 主机页卡片「…」菜单 |
| 编辑主机连接（模式、端口、唤醒 MAC、SSH 重连） | 设置 → 服务器 → 编辑 | 设置 → 服务器（保留）；主机卡片「…」菜单增加入口 |
| 添加主机：扫码配对、已连接电脑（Slingshot）、SSH / URL | 「+ 服务器」→ 选择卡片 | 主机页「扫码连接」直接打开扫码配对；「+」打开完整添加面板 |
| 项目选择、新建项目（目录选择器） | 首页输入框的项目 chip | 项目页（每行显示所属主机）、新建任务面板的项目 chip |
| 新建任务（模型 chip、附件、听写、全屏编辑） | 首页「+」→ 输入框 | 任务 / 项目页底部「有个想法？交给搭子…」胶囊 → 新建任务面板 |
| 实时语音 | 首页麦克风胶囊（`realtime_voice`） | 输入胶囊的语音按钮，沿用 `realtime_voice` |
| 设置 | 首页左上齿轮 | 任务页右上角齿轮 |
| Saved Apps | 首页网格图标（有保存的 App 时）、设置 | 任务页「…」菜单（有内容时）、设置 |
| 本地终端 | 首页终端图标（`terminal` 开关） | 任务页「…」菜单（沿用开关） |
| 首页缩放 1–4 级详情 | 双指缩放、顶部按钮 | 设置「首页显示任务详情」开关，沿用 `dashboardZoomStep` |
| 宠物、实验功能、账号 | 设置 | 设置（不变） |
| 会话 Header：模型 / 推理 / 目录 / 计划 / 完全访问标记、重新加载、会话信息 | 会话顶部 | 标题栏显示任务标题和「搭档 · 主机」；模型、权限、任务信息、重新加载放进「…」菜单 |
| 输入框：斜杠命令、@文件、附件、听写、排队 / 引导、目标、计划进度、全屏编辑 | 会话底部 | 同一位置，换成 Mint 输入框，补齐空闲 / 执行中 / 正在停止 / 断线 / 创建中状态 |
| 审批（命令、文件、权限；拒绝 / 本会话允许 / 允许） | 全局遮罩弹层 | 会话内显示在输入框上方的审批卡，其他页面显示顶部横幅 |
| 用户输入请求 | 输入框上方 + 全局弹层（重复显示） | 仅输入框上方的问题卡 |
| 会话信息、壁纸、终端、实时语音、Saved App 详情 | 各自页面 | 保留页面，换 Mint 外观 |
| 通知进入任务、前台通知抑制 | `MainActivity` + `activeThread` 路由 | 不改 |

### 计划删除的内容（与 iOS 一致）

| 旧内容 | 处理 |
|---|---|
| 首页新手引导气泡（`OnboardingCoachmarks.kt`） | 删除 |
| 空态小猫、动画 Logo（`AnimatedLogo.kt`） | 删除，空态改为带明确下一步的 `BuddyEmptyState` |
| 无行为的示例建议（`AmbientSuggestionsList.kt`） | 删除 |
| 首页双指缩放（`DashboardZoomPrefs.kt` 的手势） | 改为设置开关，存储沿用 |
| 主机胶囊行（`ServerPillRow.kt`） | 由任务页主机菜单和主机页替代 |
| 旧首页（`HomeDashboardScreen.kt` 等） | 由任务 / 项目 / 主机三页替代 |

## 2. 特性开关

| 开关 | 默认 | 控制 |
|---|---|---|
| `realtime_voice` | 开 | 首页语音按钮、会话输入框实时语音 |
| `thinking_minigame` | 关 | 会话中的小游戏 |
| `terminal` | 关 | 本地终端入口、服务器 Shell |

重构不改默认值，也不启用原本关闭的实验特性。

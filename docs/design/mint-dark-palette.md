# Mint 深色配色：石墨灰与薄荷绿

2026-09-29。适用 iOS / Android 默认 `agentbuddy-mint-dark` 主题。

## 设计方向

阅读区域使用中性石墨灰，去掉原来背景、卡片、代码区和文字的绿色色偏。通过亮度区分页面、卡片和输入区域；文字使用柔和灰白，不使用纯白。薄荷绿集中在主操作、链接和状态提示。

当前任务卡片使用低亮度、低饱和度的强调底色，避免大面积浅绿在夜间过亮。卡片文字接近灰白；内部 chip 根据品牌底色的亮度选择填充，深色底上只叠加 8% 的 onBrand，浅色品牌底保持原有 45% 白色。

## 两端接入

- iOS 从 `Resources/Themes/agentbuddy-mint-dark.json` 加载；Android 的 Gradle assets 直接引用同一目录。
- `theme-manifest.json` 的预览色同步更新，主题 slug 保持不变。
- 两端 `brandChipFill` 都根据实际品牌底色亮度计算，兼容用户选择的其他主题。
- 浅色 Mint 配色不变。未修改共享 Rust、主题偏好和主题解析接口。

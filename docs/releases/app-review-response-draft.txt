Guideline 4.3(a)
AgentBuddy is an independently maintained open-source derivative. We acknowledge its upstream foundations and do not claim that a new icon alone makes it a different product. The reviewed build was 1.5.0 (202609251324). The repository now includes changes made after that build: dedicated Tasks / Projects / Hosts navigation; task sections for decisions requiring attention, running work, and recent conversations; inline approval results; recent tasks within project cards; and MyFlicker integration for appropriately configured hosts.

Using the existing host setup instructions, open Tasks to find work requiring a decision, open its conversation and respond to the approval, then open Projects to resume a recent task in that project. Hosts provides connection and available-runtime controls. These are workflow changes; project management, multiple agents, and approvals also existed in our upstream foundations.
